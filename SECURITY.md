# Security

Keep Hytale session files, keys, browser authorization URLs, bridge tokens, and unreviewed logs private.

Request a private reporting channel through GitHub Discussions. Give the addon version, launcher build, and a description with synthetic inputs. Share sensitive details only through the private channel.

The package status records separate results for safe checks, package inspection, actual Windows validation, and live Hytale checks. Record the exact ZIP hash with the Windows and live results. Mark a result as passed only after the corresponding check completes.

For Windows validation, use a designated disposable VM. Verify normal UAC, alternate administrator refusal, actual SYSTEM and limited repair identities, and access rejection for another Windows user. Preserve package and source hashes with the observations. Retain the recovery journals until restoration succeeds.
